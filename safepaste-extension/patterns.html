SafePaste pattern library

v1 rules run locally in your browser. No network calls. Placeholders and obvious documentation tokens are skipped when detection is uncertain.

Tier 1 — high confidence

  • Database URLs (postgresql://, mysql://, mongodb://, mongodb+srv://, redis://) — password segment only
  • Environment assignments where the key name suggests a secret (SECRET, TOKEN, API_KEY, PASSWORD, DATABASE_URL, PRIVATE_KEY, ACCESS_KEY, AUTH, …)
  • Authorization: Bearer … — opaque tokens and JWTs
  • JWT-shaped strings (three Base64URL segments)
  • PEM private key blocks

Tier 2 — known formats

  • Anthropic API keys (sk-ant-api##-…) — public prefix preserved
  • OpenAI API keys (sk-…, excluding Anthropic) — prefix preserved where matched
  • GitHub tokens (ghp_, gho_, ghs_, ghu_)
  • AWS access key IDs (AKIA…, 20 characters)
  • Stripe secret keys (sk_live_, sk_test_)
  • Generic long high-entropy values next to labels like api_key, client_secret, …

Replacement tokens

  • [REDACTED] — passwords, env values, opaque bearer tokens, vendor key tails
  • [REDACTED_JWT] — JWT-shaped material
  • [REDACTED_KEY] — PEM private key material
